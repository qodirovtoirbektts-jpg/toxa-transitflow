# TransitFlow (Toxa) — Global Freight Forwarding, Cargo & Logistics Ecosystem UI

An enterprise logistics, ocean shipping, and multimodal supply chain web platform UI for **TransitFlow**, featuring real-time container telematics tracking, interactive freight tariff estimator, and operational dispatch centers.

## ✨ Features
- **Maritime Logistics Aesthetic**: Enterprise navy (`#091322`), safety amber (`#ffbe1a`), clean slate cards with Rajdhani and Inter typography.
- **Real-Time Cargo Radar Widget**: Dynamic code lookup with live vessel GPS coordinates, temperature telemetry, and ETA calculation.
- **Interactive Multimodal Freight Rate Calculator**: Spot rate calculation across Ocean FCL, Air Cargo Priority, and Silk Road Rail based on payload tonnage.
- **Live Shipment Milestone Timeline**: 5-stage visual delivery tracker from origin pickup to final distribution delivery.
- **Enterprise Fleet & Port Corridors**: Capabilities across 140+ international ports with 24/7 global dispatch integration.
